# Yashika Singh — Portfolio

A modern recruiter-focused portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Important edits before publishing

Open `src/main.jsx` and update:
- `yashika@example.com` → your real email
- LinkedIn URL → your real LinkedIn profile
- Project GitHub/demo URLs → your actual repositories/deployments
- Internship dates if you want to show exact dates
- Education details if you want to add graduation year/percentage

The UI is already responsive for desktop, tablet and mobile.
